Entry for the make.fun competition **One Word From Your Ex**: exactly one word
the entrant's ex would use to describe them. Winner takes the whole $2 reward.

The word: **placeholder** — the guy who was only ever keeping the seat warm
until someone better came along.

`main.ts` writes the word to `/output/entry.txt` (11 characters, one word,
inside the 1–24 character gate).
